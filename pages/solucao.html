  • Otimização drástica da Supply Chain

Satélites Sentinel

Copernicus Data Space (ESA)

A Agência Espacial Europeia fornece a API OData do programa Copernicus. É a fonte principal para mapeamento de temperatura do solo e anomalias de umidade.

Endpoint: /odata/v1/Products
Foco: Dengue e Zika
Missão GPM

NASA POWER & GPM API

Projeto de Ciência Aberta da NASA. O sensor GPM é essencial para medir precipitação extrema (chuvas torrenciais) em zonas remotas.

Saída: JSON / NetCDF
Foco: Cólera e Leptospirose
Dados Nacionais

INPE - CPTEC & BDQueimadas

O Instituto Nacional de Pesquisas Espaciais fornece os modelos climáticos locais e o monitoramento em tempo real de focos de calor e fumaça.

Cobertura: Brasil
Foco: Crises Respiratórias
Resposta a Desastres

International Space Charter

Consórcio global que libera imagens de altíssima resolução imediatamente após grandes desastres naturais para ajudar na logística emergencial.

Caso de Uso: Rotas de Última Milha
Ativação: Sob demanda

Documentação de Integração (OpenAPI)

Especificação técnica do Hub Preditivo exposto para o SUS e Indústria Farmacêutica (B2G/B2B).

openapi.yaml
openapi: 3.0.3
info:
  title: AstroPharma API - Documentação do Hub Preditivo
  description: >
    API B2B/B2G do AstroPharma. Consome telemetria geoespacial (ESA, NASA, INPE) 
    e expõe endpoints de alertas epidemiológicos e recomendações logísticas 
    preventivas.
  version: 1.0.0
servers:
  - url: https://api.astropharma.space/v1
    description: Servidor de Produção (MVP)

paths:
  /alertas:
    get:
      summary: Retorna os alertas epidemiológicos ativos
      parameters:
        - name: regiao
          in: query
          required: false
          schema:
            type: string
        - name: risco
          in: query
          required: false
          schema:
            type: string
            enum: [ALTO, CRITICO, MODERADO]
      responses:
        '200':
          description: Lista de alertas recuperada com sucesso.
          content:
            application/json:
              schema:
                type: array
                items:
                  $ref: '#/components/schemas/AlertaEpidemiologico'

  /alertas/{id}/dossie-preventivo:
    get:
      summary: Emite o dossiê documentado para ação do cliente
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: string
      responses:
        '200':
          description: Dossiê gerado com sucesso.
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/DossieLogistico'
