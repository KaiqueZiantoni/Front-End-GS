# AstroPharma | Logística Orbital Preditiva

Projeto desenvolvido para a **Global Solution 2026/1** da FIAP. A AstroPharma é uma solução SaaS focada em BI Preditivo para a cadeia de suprimentos farmacêutica, utilizando dados meteorológicos espaciais para antecipar demandas e evitar rupturas de estoque.

## Sobre o Projeto
O sistema utiliza IA para correlacionar eventos climáticos (monitorados via dados de satélite) com o consumo de medicamentos. A interface Front-End foi desenvolvida para oferecer uma experiência intuitiva (Total Experience) para gestores logísticos, permitindo a visualização de riscos e o gerenciamento de reposições.

## Tecnologias Utilizadas
* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** Estilização modular com foco em responsividade e design moderno.
* **JavaScript (ES6+):** Lógica de interatividade (menu hambúrguer, acordeon de FAQ, validação de formulários).
* **IBM Watson Assistant:** Integração de chat inteligente para suporte e consulta de dados em tempo real.
* **Google Fonts:** Tipografia *Inter* para legibilidade.
